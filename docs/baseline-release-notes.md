## Evolux — baseline funcional nativo Kotlin

Esta release registra a versão funcional do Evolux antes de qualquer nova personalização visual.

O APK usa Kotlin nativo, Jetpack Compose/Compose for TV, player Media3/ExoPlayer, autenticação por MAC lógico, M3U e Xtream, cache local, separação de canais/filmes/séries, capas oficiais de séries e temporadas/episódios carregados sob demanda.

Futuras alterações de identidade visual devem modificar somente a Home e seus componentes visuais. Parser, XtreamRepository, cache, player, autenticação, modelos e callbacks de navegação devem permanecer preservados.
